# natural-earth

Every vector layer of [Natural Earth](https://www.naturalearthdata.com/) at
the three scales it publishes, 1:10m, 1:50m and 1:110m, cultural and
physical: countries and their point-of-view variants, states and provinces,
boundary lines, populated places, roads, railroads, airports, ports, urban
areas, time zones, coastlines, land, ocean, lakes, rivers, glaciers,
bathymetry, graticules and more. One GeoParquet file per layer, beside the
publisher's zips unchanged.

Public domain (see Licence).

## Subsets

One subset per layer, named after it (`ne_10m_admin_0_countries`,
`ne_110m_land`, ...). Every file is GeoParquet 1.0 with a `geometry` column
in EPSG:4326 (longitude, latitude), and every attribute field of the
shapefile under its own name.

```python
from datasets import load_dataset
ds = load_dataset("yuiseki/natural-earth", "ne_110m_admin_0_countries", split="train")
```

```sql
-- DuckDB
load spatial;
select NAME, ST_Area(geometry) from 'hf://datasets/yuiseki/natural-earth/parquet/v5.1.2/110m_cultural/ne_110m_admin_0_countries.parquet';
```

## Where it comes from

- Layer list: the tree of the latest release tag, v5.1.2 (commit
  f1890d9f152c, released 2022-05-13), of
  <https://github.com/nvkelso/natural-earth-vector>, the repository the
  distribution is built from: every `.shp` under `10m_cultural/`,
  `10m_physical/`, `50m_cultural/`, `50m_physical/`, `110m_cultural/` and
  `110m_physical/`. The CDN itself has no listing.
- Files: `https://naciscdn.org/naturalearth/<scale>/<category>/<layer>.zip`,
  the zips the download buttons on naturalearthdata.com serve. A layer the
  CDN does not serve on its own comes from the bundle the download page
  links for it (`ne_10m_parks_and_protected_lands.zip`) or from the theme
  package `<scale>_<category>.zip`; the table below names that zip.
- Fetched 2026-10-06. Everything under `raw/` is as served, with
  `raw/v5.1.2/MANIFEST.json` recording URL, size, sha256, Last-Modified and
  the VERSION.txt of every zip.

## Versions

There is no one version. The directory is named after the GitHub release
(v5.1.2), but the CDN URLs carry no version and each zip declares its own in
`<layer>.VERSION.txt`; the `version` column below is that file, and the
Parquet key-value metadata `natural_earth_version` repeats it. The download
pages state yet another version next to each link (recorded in the
manifest). Natural Earth has not released since May 2022: boundaries,
names and places are as of then.

Natural Earth shows de facto boundaries by default; the
`ne_10m_admin_0_countries_<iso>` layers are the point-of-view variants.

## What the Parquet changes

- Columns are the `.dbf` fields in order, then `geometry`; nothing added,
  renamed or dropped.
- Types come from the `.dbf` field definitions: C as VARCHAR, N without
  decimals as INTEGER (width up to 9) or BIGINT (10 to 18), N with decimals
  and F as DOUBLE, L as BOOLEAN, D as DATE.
- Text decoded in the encoding the layer's `.cpg` names (UTF-8 everywhere it
  is present), written as UTF-8. Empty text, empty or `*` numbers and
  `00000000` dates are NULL, as GDAL reads them.
- Geometry unchanged: no reprojection, no repair, no simplification.
  Invalid geometries are counted below (`invalid`, by ST_IsValid) and left
  as Natural Earth ships them.

Every Parquet file was checked against its shapefile: the feature count
against the `.dbf` and the `.shx`, every cell against an independent Python
reading of the `.dbf`, and every geometry's WKB against GDAL's reading.
